# 배드민턴 동호인대회 대시보드

기존 단일 HTML과 대회 데이터·원문 링크·5개 필터(전체/신규·접수 임박/전국/충청권/충주시)를 유지합니다. 새 디자인이나 중고 매물 보드는 포함하지 않습니다.

## 수집 범위
- 전국 동호인·전국오픈: 지역 무관.
- 시·군·구 단위: 충주시만.
- 도 단위: 충청북도·충청남도만.
- 전문선수·학교 선수 대회, 타 지역 시군구 대회는 제외합니다. 지역 미확인 신규 후보는 자동으로 포함하지 않습니다.
- 공지 사이트와 실제 접수 방법을 구분하며 원문 상세를 검증하지 않은 새 항목의 급수·성적기간·승급 기준은 미확인으로 표시합니다.

## 6개 출처와 실패 보존
위꾹, 페이스콕, BKPLAY, 스포넷, 전국배드민턴대회, 오마이민턴을 각각 조회합니다. 앱 소개 페이지의 HTTP200은 대회 목록 조회 성공이 아닙니다. 출처별 결과·마지막 시도·마지막 완전 정상조회·상세 실패를 표시합니다. 빈 파싱이나 실패 때문에 이전 대회·요강·출처 링크를 삭제하지 않습니다. 같은 플랫폼 ID 또는 검증된 제목/개최일이 같은 행사는 합치고 출처 링크를 모두 유지합니다.

## 파일
- `dashboard.template.html`: 기존 화면·필터의 공개용 템플릿.
- `data/tournaments.json`: 공개 정보만 남긴 기준선과 출처 상태.
- `scripts/collect.mjs`: 익명 읽기 전용 수집기. 로그인·참가신청을 실행하지 않습니다.
- `scripts/lib.mjs`, `scripts/adapters.mjs`: 실패 보존·필터·중복통합·출처 구조 파서.
- `scripts/render.mjs`: 인라인 데이터와 정적 카드/행을 함께 갱신합니다.
- `site/`: Pages로 배포할 유일한 디렉터리.
- `tests/`: 원본 유지·실패 보존·개인정보 제거 회귀 테스트.

## 실행
Node22 이상에서 `npm ci`, `npx playwright install --with-deps chromium` 후:
- `npm test`
- `npm run collect -- --probe`: 실제 출처 조회, 기존 대회 기준선은 수정하지 않음.
- `npm run build -- --state reports/probe-state.json`
- `npm run scan`
- `npm run test:browser`
로컬 시험에는 `npm run collect -- --local --probe`처럼 `--local`을 명시해야 하며 클라우드 시험으로 보고하지 않습니다.

## GitHub Actions 전환 절차
1. 비공개 준비 저장소에서 **Cloud source check (no publication)**을 수동 실행합니다. Pages 권한이 없고 공개할 수 없는 워크플로입니다.
2. 출처 결과·브라우저 검사·공개 파일 검사를 검토합니다. 사용자에게 공개 내용과 예상 주소를 보여주고 명시적 승인을 받습니다.
3. 승인 후 전용 저장소 공개 범위와 Pages 설정을 적용하고 `PAGES_PUBLISH_APPROVED=true` 저장소 변수를 설정합니다. 승인 전에는 이 변수를 설정하지 않습니다.
4. **Update existing dashboard and deploy Pages**를 수동 실행합니다. `site/`만 배포하고, 저장된 로그인 없이 같은 HTTPS 주소의 실행ID와 390×844 화면을 검증합니다.
5. 수동 배포가 검증된 후에만 주간 예약 주석을 해제합니다: `0 0 * * 1`(UTC 월요일00시 = 한국 월요일09시). GitHub 예약은 정확히 그 분에 시작한다고 보장되지 않습니다.
6. 첫 `schedule` 이벤트의 실제 실행과 같은 공개 주소의 반영까지 확인합니다. 그 전에는 맥북 기존 Aside 루틴을 끄거나 데스크탑에 같은 수집 루틴을 만들지 않습니다.

현재 파일은 예약 활성화 전 준비본입니다. 공개 승인·실제 클라우드 실행·실제 배포를 완료했다는 뜻이 아닙니다. Pages와 Actions는 별개이며, Pages가 열려도 수집 실패 시 최신 정보가 아닐 수 있습니다. 화면의 마지막 성공 시각을 확인하세요.

## 개인정보·키
연락처·이메일·입금번호·개인 경로를 공개 데이터에서 제거합니다. 문의와 결제 정보는 원문 링크에서 확인하도록 안내합니다. 로그인 정보·인증키·중고 매물·개인 검색 기록·인계 문서 전체는 공개하지 않습니다. 자동 토큰은 Actions의 기본 단기 권한만 사용하고 공개 파일에 저장하지 않습니다. 배포는 명시적인 `site/` 허용 목록과 개인정보 검사 뒤에만 실행합니다.
